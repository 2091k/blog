#### 命令bat代码 放到需要重新命名文件的文件夹

```
@Echo Off & SetLocal ENABLEDELAYEDEXPANSION
FOR %%a in (*.pdf) do (
    set "name=%%a"
    set "name=!name:(=!"
    set "name=!name:)=!"
    for /f "tokens=* delims= " %%s in ("!name!") do set "name=%%s"
    :: 去尾空格
    for /l %%i in (1,1,31) do if "!name:~-1!"==" " set "name=!name:~0,-1!"
    ren "%%a" "!name!"
)
exit
```
