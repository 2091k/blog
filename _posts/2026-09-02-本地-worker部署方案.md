# 本地 Cloudflare Worker 部署方案

## 方案概述

本方案介绍如何在本地运行 Cloudflare Worker，提供一个简单的项目配置示例。

---

## 方案 1：新建 `wrangler.toml`（最简单，推荐）

### 步骤

在 `D:\bt\x86\ai-agent\` 创建 `wrangler.toml`，内容如下：

```toml
name = "douyin-parse"
main = "workers.js"
compatibility_date = "2026-07-29"
```

> **提示**：`2026-07-29` 是你本地 `workerd` 支持的最大日期，解析代码完全不需要高于这个日期的新特性。

### 启动方式

执行以下命令启动本地开发服务器：

```bash
wrangler dev --local --port 8787
```

启动后，在浏览器访问 `http://127.0.0.1:8787` 即可测试。

---

## 关键配置说明

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `name` | `douyin-parse` | Worker 项目名称 |
| `main` | `workers.js` | 入口文件 |
| `compatibility_date` | `2026-07-29` | 兼容性日期，需匹配本地 workerd 支持的最大版本 |
