# Codex+DeepSeek 与Codex-X安装方法

### Codex（OpenAI）下载安装教程

1.官网下载[https://openai.com/zh-Hans-CN/codex/](https://openai.com/zh-Hans-CN/codex/)
调用应用商店下载安装

2.下载离线安装包手动安装

- 打开网站：[https://store.rg-adguard.net](https://store.rg-adguard.net)

```
ProductId     9PLM9XGG6VKS       RP
```
- 下载`OpenAI.Codex_26.803.10989.0_x64__2p2nqsd0c76g0.msix`
可下载最新版本

- 移动云盘安装包
> 链接: [https://yun.139.com/shareweb/#/w/i/2wFGwJDdsbivb](https://yun.139.com/shareweb/#/w/i/2wFGwJDdsbivb)  提取码:`wf4e`

#### 离线安装命令（管理员 PowerShell）

shift+右键 打开PowerShell 

```powershell
Add-AppxPackage -Path ".\OpenAI.Codex_26.803.10989.0_x64__2p2nqsd0c76g0.Msix"
```

# Codex-X安装

- 上方链接下载好后，解压打开Codex-X

- 然后进行配置就行了，自己先申请deepseek  api

# 使用Codex

- 首次打开Codex 填写token

- sk-

- 可以填申请的deepseek api 也可以随便填sk-1234

- 随便填的话 打开后重新配置一下Codex-X在重新打开Codex
