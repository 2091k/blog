# 魏无羡影院 —— 从 Cloudflare Workers 迁到 Ubuntu 盒子（nginx + PHP）

[https://wwbda.lanzouv.com/iIzkn4ff234j](https://wwbda.lanzouv.com/iIzkn4ff234j)

目标：`http://192.168.41.102:6001/` 直接打开视频主页，所有接口都在盒子上跑，新增影片走后台，不再改 `img.txt`、也不再往仓库里建空的 `xxx.html`。

## 二、目录结构

```
/var/www/vqq/
├── index.html            首页（已改成调 /api/*）
├── player.html           播放页（已改成调 /api/play）
├── admin.html            后台（登录后可增删改片单）
├── api/
│   ├── index.php         接口路由（所有 /api/* 都进这里）
│   ├── vqq.php           采集层：qiyou04 搜索/详情/播放地址
│   └── store.php         数据读写 + 后台登录鉴权
├── data/                 ★ 只有 www-data 能写，nginx 里已禁对外访问
│   ├── videos.json       片单（后台改的就是它）
│   ├── config.json       后台密码 + 分类表 + 源站域名（首次访问自动生成）
│   ├── cache/            抓取缓存（详情页缓存 6 小时）
│   └── img.txt.legacy    旧的 img.txt，留个底，不参与运行
├── deploy/
│   ├── vqq-nginx.conf    nginx 站点配置（listen 6001）
│   ├── install.sh        一键安装
│   └── selftest.sh       装完自检
└── tools/                迁移/改造脚本，只在电脑上跑，盒子用不到
```

## 三、上传

三种任选，最终要落到 `/var/www/vqq`：

**方式 1：WinSCP / FileZilla**
主机 `192.168.41.102`，端口 `22`，用户 `root`，把 `vqq-ubuntu` 整个文件夹拖到 `/var/www/`，然后把文件夹名改成 `vqq`。

**方式 2：压缩包（推荐，一个文件传完）**
```bash
# 先把 vqq.tar.gz 传到 /tmp，然后在盒子上执行
mkdir -p /var/www
tar xzf /tmp/vqq.tar.gz -C /var/www
ls /var/www/vqq        # 应该能看到 index.html / api / data ...
```

**方式 3：scp（在 Windows PowerShell 里）**
```powershell
scp -r D:\bt\x86\ai-agent\ai\vqq-ubuntu root@192.168.41.102:/var/www/vqq
```

> 传完先确认一句：`ls /var/www/vqq/api/index.php` 存在，再往下走。

## 四、安装（一条命令）

```bash
sudo bash /var/www/vqq/deploy/install.sh
```

脚本做的事（每步都有回显，出错会自己撤销）：

1. `chown -R www-data:www-data /var/www/vqq/data`，建 `data/cache`（**漏了这步后台保存会报 500**）；
2. 把 `deploy/vqq-nginx.conf` 装到 `/etc/nginx/sites-available/vqq`（已有同名文件先备份）；
3. 软链到 `/etc/nginx/sites-enabled/vqq`；
4. `nginx -t` 检查，不通过就撤销这次的软链，**不影响你现在 80 端口上的站点**；
5. `systemctl reload nginx`，然后自己 curl 一次 `/api/home` 报状态码。

装完打开：

- 主页：`http://192.168.41.102:6001/`
- 后台：`http://192.168.41.102:6001/admin.html`（或 `/admin`），**默认密码 `vqq@2026`，登录后第一件事改掉**

## 六、后台怎么用

打开 `/admin.html`，输密码登录。左边「功能列表」五块，点哪个右边就切到哪个：

**① 影片管理**
- 「添加影片」：填 **影片名称**、**分类（下拉选，只能选已有分类）**、**图片链接**（腾讯视频封面地址，留空就是占位图），右边实时预览封面；
- 保存后首页刷新即可看到，顺序就是添加顺序，列表里 `↑ ↓` 可调同一分类内的位置；
- 「编辑」改名称/分类/封面，「删除」直接移除；
- 上面可按名称筛选、按分类筛选；筛选条件一改就自动回第 1 页；
- **列表分页显示，每页 20 部**（现在的 68 部就是 4 页），底部一排：`首页 / 上一页 / 第 X / Y 页 · 共 N 部 · 每页 20 部 / 下一页 / 末页`，已经在首页或末页时对应按钮自动变灰；
- **新加的片子排在所属分类的最前面**（首页、`/list`、后台列表用的都是这个顺序），不用再手动上移；保存后列表会自动切到该分类、回到第 1 页，第一行就是它；

**② 分类管理**
- 输入分类名（比如「综艺」「纪录片」）点「添加分类」，首页立刻多一个标签，影片管理的下拉里也能选到；
- 有影片的分类不能删（按钮是灰的），先把影片删掉或改到别的分类；
- 空分类可以删，删掉后首页对应标签消失。

**③ 导入 / 导出**
- 「导出片单 JSON」下载整份片单（`title / type / img`），当备份；
- 「导入」选 JSON 文件，两种方式：**合并**（已有的不动，只补新片，同名同分类自动跳过）、**覆盖**（先清空再照文件重建）；
- 文件里的新分类会自动加到分类表；导入完会回显「新增 x 部、跳过 y 部、格式不对 z 条、现在共 n 部」；
- 文件格式：`{"videos":[{"title":"片名","type":"电影","img":"https://..."}]}`，`img` 可以留空。

**④ 站点配置**
- 「源站地址」只填协议+域名（例如 `http://www.qiyou04.com`），带路径会被拒绝；
- 保存后立即生效，并且**自动清空详情缓存**；「测试能不能打开」会拿当前域名搜一次「棋士」，能返回结果就说明源站活着；
- 这个源站哪天打不开了，换成结构相同的站即可（`/search.php`、`/view/{id}.html`、`/play/{id}-{源}-{集}.html`）；
- 「清空详情缓存」用于强制重新抓一遍。

**⑤ 修改密码**
- 至少 6 位；改完 `config.json` 里 `is_default` 变 false。

> 名称重复会被拒绝（同分类内不允许同名），因为播放页是拿名称去源站搜的。

## 七、几个技术点（避免以后踩坑）

- **为什么不用 PHP 的 curl**：这台盒子的 PHP 7.4 没装 `php7.4-curl`。所以单页抓取用 `file_get_contents`（`allow_url_fopen` 已开），搜索结果这种「一次要抓十几页」的场景，用原生 `socket + stream_select` 并发抓，14 路并发，30 条结果约 3-5 秒。想更快可以 `apt install php7.4-curl`（不装也能正常用）。
- **缓存**：详情页按 ID 缓存 6 小时（`data/cache/view_<id>.json`），重复搜索同一批片子基本秒回。想强制刷新就删 `data/cache/` 里的文件。
- **登录态**：PHP 原生 session（cookie 名 `vqqsid`），12 小时过期；连续输错 8 次锁 5 分钟（`data/.login.json`）。
- **端口**：6001 是独立 server 段，和你 80 端口的 `default` / `nginx_any168` / `nginx_radio` / `nginx_webdav` 四个站点互不干扰，不用动它们。
- **必须是 http**：源站搜索/详情页是 http，播放 iframe 现在给的是 https 的 `meizi.yongfan99.com`，两种都能过；站点用 `http://` 访问最稳，不要强行套 https 反代，否则容易撞混合内容。
- **数据目录不能公开**：`videos.json`、`config.json` 在 `data/` 里，nginx 对 `/data/` 一律 `return 404`，别把 data 挪出站点根目录乱放。

## 八、回滚 / 停用旧 Worker

回滚（站点立即消失，文件都还在）：

```bash
rm /etc/nginx/sites-enabled/vqq
nginx -t && systemctl reload nginx
```

确认新站稳定后，Cloudflare 上这几个可以直接删掉/停用：`vqqadmin`、`vqq2026`、`jasu`、`vqqimg`（`vqqadmin` 还依赖 GitHub token，一起作废就行）。

## 九、出问题先看这里

| 现象 | 排查 |
| --- | --- |
| 主页 404 / 502 | `tail -50 /var/log/nginx/vqq.error.log`；`systemctl status php7.4-fpm` |
| 接口 502 | 一般是 php-fpm 没起，或 `fastcgi_pass` 的 socket 路径不对（本机是 `/run/php/php7.4-fpm.sock`） |
| 后台能登录但保存 500 | `data/` 权限问题：`chown -R www-data:www-data /var/www/vqq/data` |
| 首页空白、弹「首页加载失败」 | F12 看 `/api/home` 是否 200；`data/videos.json` 格式被改坏就看 `.bak` |
| 搜索转圈很久 | 源站慢或被墙，先 `curl -I http://www.qiyou04.com/` 看通不通 |
| 封面不显示 | 封面是腾讯外链，有些地址只有 `http://`，浏览器会按 `onerror` 显示占位 |
| 播放黑屏 | `/api/play` 返回的 url 为空，说明源站那集的 iframe 结构变了 |
