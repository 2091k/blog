## 标题

# DeepSeek++ 新手食用教程 🚀


## 📖 前言

大佬们的帖子各种跳、话简短，新手看得一头雾水。这篇教程把所有步骤串起来，**手把手**教你如何在网页版 DeepSeek 上使用 MCP 连接 MT 管理器，实现 **无限 Token** 自由！

### 🎯 整体架构

```
浏览器(DeepSeek++) → localhost:9999(代理) → 手机MT管理器MCP(局域网IP:端口)
```

### 📋 你需要准备

- 一台 **电脑**（Windows/Mac/Linux 均可）
- 已安装 **Node.js** 环境
- 一台 Android 手机，安装了 **MT 管理器**（需在同一局域网）
- 一个能翻墙的网络环境（用于下载 Chrome 插件）
- Chrome/Edge 浏览器

## 第二步：打开 MT 管理器的 MCP 功能

在手机上打开 **MT 管理器**，进入 MCP 功能模块。

你会看到类似这样的界面，记录下显示的 **IP 地址**和**端口号**（例如 `192.168.41.123:8787`）。

> ⚠️ **重要**：确保手机和电脑在**同一个局域网**下（连同一个 WiFi），否则后面代理连不上！

## 第三步：配置反向代理

### 为什么需要反向代理？

因为浏览器的安全策略会发送 `Origin` 和 `Referer` 头，MT 管理器的 MCP 服务会拒绝这些请求。我们需要一个**本地代理**把这些头去掉。

### 3.1 安装 Node.js

如果还没装，先去 [Node.js 官网](https://nodejs.org/) 下载安装 LTS 版本。
- 也可以下载我是上传好的[蓝奏云-node安装包](https://wwbda.lanzouv.com/ieQCP41tmbtc)

### 3.2 创建代理脚本

在电脑上新建一个文件，命名为 `proxy.js`，复制以下代码：

```javascript
// proxy.js - 去掉 Origin 头转发到 MCP 服务
const http = require('http');

// ⚠️ 把下面两个值改成你 MT 管理器上显示的实际 IP 和端口！
const TARGET_HOST = '192.168.41.123';  // 改成你的 MT 管理器 IP
const TARGET_PORT = 8787;            // 改成你的 MT 管理器端口
const PORT = 9999;                   // 本地代理端口，一般不用改

http.createServer((req, res) => {
  const options = {
    hostname: TARGET_HOST,
    port: TARGET_PORT,
    path: req.url,
    method: req.method,
    headers: req.headers,
  };

  // 关键：去掉这两个请求头
  delete options.headers.origin;
  delete options.headers.referer;

  const proxyReq = http.request(options, (proxyRes) => {
    res.writeHead(proxyRes.statusCode, proxyRes.headers);
    proxyRes.pipe(res);
  });

  proxyReq.on('error', (e) => {
    res.writeHead(502);
    res.end('代理错误: ' + e.message);
  });

  req.pipe(proxyReq);
}).listen(PORT, () => {
  console.log(' 代理已启动: http://localhost:' + PORT);
  console.log(' 转发目标: ' + TARGET_HOST + ':' + TARGET_PORT);
});
```

> 💡 **补充说明**：此代理代码来自清闲大佬的原帖，核心原理是**去掉 Origin 和 Referer 头**后转发请求到手机端的 MCP 服务。字节数限制大佬改为 `1000000`。

### 3.3 启动代理

在`proxy.js`目录新建一个`start.cmd`直接运行

```sh
@echo off
:: 进入bat脚本所在目录
cd /d "%~dp0"
node proxy.js
:: 执行完毕暂停，窗口不关闭
pause
```
---
### 或者
打开终端（CMD/PowerShell/终端），`cd` 到 `proxy.js` 所在目录，运行：

```bash
node proxy.js
```

看到以下输出说明代理启动成功：

```
✅ 代理已启动: http://localhost:9999
📡 转发目标: 172.16.14.27:8787
```

> 💡 **小贴士**：也可以用 **nginx** 替代 Node.js 做反向代理，原理一样，这里不展开。

## 第四步：配置 DeepSeek++ 插件的 MCP

### 4.1 打开 MCP 配置

点击浏览器右上角的 **DeepSeek++ 插件图标** → 找到 **MCP 设置**。

### 4.2 新建 MCP 服务

按照下表配置：

| 配置项 | 值 |
|--------|-----|
| 🔗 **服务 URL** | `http://localhost:9999/mcp` |
| 📏 **最大字节数** | `1000000` |

> ⚠️ **注意**：
> - URL 结尾一定要带 `/mcp`，不要只填 `http://localhost:9999`
> - 字节数填 **1000000**（清闲大佬亲测有效的值）

配置完成后**保存**。

## ❓ 常见问题

| 问题 | 解决方法 |
|------|----------|
| 🔴 连不上 MCP | 检查手机和电脑是否同一局域网；确认 `proxy.js` 正在运行 |
| 🔴 代理报错 502 | MT 管理器的 IP/端口填错了，核对后重启代理 |
| 🔴 插件安装失败 | 尝试用 GitHub Release 的离线包手动安装 |
| 🔴 手机能用吗？ | 不行，作者明确说了目前只支持电脑端 |
| 🔴 能不能连 PC 端 Trae？ | Trae 有验证，端口不公开，搞不了 |
